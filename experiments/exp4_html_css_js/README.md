# Experiment 4: HTML Structure, CSS Styling & JavaScript Interactivity

## Objective
To demonstrate HTML semantic structure, CSS styling techniques (Inline, Internal `<style>`, and External stylesheet), and vanilla JavaScript interactivity for dynamic DOM updates and style manipulation.

## Source Files
- [`index.html`](index.html) — Structure with inline and internal CSS.
- [`styles.css`](styles.css) — External stylesheet with CSS custom properties (variables).
- [`script.js`](script.js) — External JavaScript for DOM event handling, grade calculation, and theme toggling.

## Concepts Demonstrated
1. **Inline CSS**: `<h1 style="color: #4f46e5; ...">`
2. **Internal CSS**: `<style> .internal-badge { ... } </style>`
3. **External CSS**: `<link rel="stylesheet" href="styles.css">`
4. **JavaScript Events**: `addEventListener("click", ...)` for updating student grades and toggling CSS classes (`classList.toggle("dark-theme")`).
