# Experiment 6: DOM Manipulation & `setInterval()` Timer

## Objective
To demonstrate DOM selection (`getElementById`, `querySelector`), content and style updates, dynamic element creation (`document.createElement`) and removal (`remove()`), event listeners, and start/pause/reset timing operations using `setInterval()` and `clearInterval()`.

## Source Files
- [`dom_timer.html`](dom_timer.html) — Layout for study stopwatch and announcement board.
- [`dom_timer.js`](dom_timer.js) — JavaScript for timer intervals and dynamic list node operations.

## Concepts Demonstrated
1. **DOM Selection**: `document.getElementById()`, `document.querySelectorAll()`.
2. **Interval Timers**: `setInterval(fn, 1000)` and `clearInterval(timerId)`.
3. **Dynamic Style & Content**: Changing `textContent` and `style.color`.
4. **Node Creation & Removal**: `document.createElement("li")`, `appendChild()`, and node `.remove()`.
